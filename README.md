# Analisador Léxico da Linguagem Pascal--

## Linguagem utilizada

- **Python** – versão **3.11.9** – 64 bits
- Utilizado o **Visual Studio Code** para o desenvolvimento.

## Instruções de Execução

### No Visual Studio Code

Basta selecionar **Run** (Executar) para compilar e executar o projeto a partir no arquivo main.py.

### Via Terminal

Utilize o comando:

```bash
& "caminho_do_python.exe" "caminho/do/projeto/pascal--/main.py"
```
